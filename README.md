# mini-project-3
Weather and Disaster Forecast System
A simple Java program that generates random weather data for multiple cities and predicts possible natural disasters.
User enters yes or no to run the system. If yes, the program simulates weather conditions for several cities and displays whether a disaster may occur.
Cities include:
Addis Ababa, Dire Dawa, Mekelle, Bahir Dar, Hawassa, Jimma, Debre Markos
